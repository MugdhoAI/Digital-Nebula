# Digital Nebula

Built an interactive 3D particle visualization featuring 15,000 particles with real time pointer driven rotation and color gradients. Pointer input covers mouse, touch and pen, and the rotation centre updates when the window is resized. Open nebula.html in a browser to run it.

Implemented using Three.js with WebGL rendering, procedural texture generation, and optimized BufferGeometry for smooth performance.

Technologies: Three.js, WebGL, JavaScript ES6
